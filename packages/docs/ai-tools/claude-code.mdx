Claude Code 是 Anthropic 官方的命令行工具（CLI）。本指南将帮助您设置 Claude Code，以协助您编写和维护文档。

## 前提条件

- 有效的 Claude 订阅（Pro、Max 或 API 访问权限）

## 设置

1. 全局安装 Claude Code：

```bash
# 全局安装 Claude Code 命令行工具
npm install -g @anthropic-ai/claude-code
```

2. 导航到您的文档目录。
3. （可选）将下方的 `CLAUDE.md` 文件添加到您的项目中。
4. 运行 `claude` 启动工具。

## 创建 `CLAUDE.md`

在文档仓库的根目录创建一个 `CLAUDE.md` 文件，用于训练 Claude Code 了解您特定的文档标准：

```markdown
# Mintlify 文档

## 工作关系

- 您可以对想法提出异议，这可能会带来更好的文档。当您这样做时，请引用来源并解释您的推理过程
- 始终要求澄清，而不是做出假设
- 永远不要说谎、猜测或编造信息

## 项目背景

- 格式：带有 YAML 前置元数据的 MDX 文件
- 配置：使用 docs.json 进行导航、主题和设置
- 组件：Mintlify 组件

## 内容策略

- 文档内容要恰到好处，足以确保用户成功使用，不多也不少
- 优先考虑信息的准确性和可用性
- 尽可能使内容具有持久性（evergreen）
- 在添加新内容之前，先搜索现有信息。除非出于战略原因，否则避免重复
- 检查现有模式以保持一致性
- 从做出最小的合理更改开始

## 页面的前置元数据要求

- title：清晰、描述性的页面标题
- description：用于 SEO/导航的简明摘要

## 写作标准

- 第二人称（"您"）
- 流程内容开始处列出前提条件
- 发布前测试所有代码示例
- 与现有页面的风格和格式保持一致
- 同时包含基本和高级用例
- 所有代码块都添加语言标签
- 所有图片都添加替代文本（alt text）
- 内部链接使用相对路径

## Git 工作流程

- 提交时永远不要使用 --no-verify 选项
- 在开始前询问如何处理未提交的更改
- 当没有明确的分支用于更改时，创建一个新分支
- 在开发过程中频繁提交
- 永远不要跳过或禁用 pre-commit 钩子

## 不要

- 跳过任何 MDX 文件的前置元数据
- 对内部链接使用绝对 URL
- 包含未经测试的代码示例
- 做出假设 - 始终要求澄清
```
