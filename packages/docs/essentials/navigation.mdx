导航菜单是每个网站上的链接列表。

每次添加新页面时，您可能需要更新 `docs.json`。页面不会自动显示。

## 导航语法

我们的导航语法是递归的，这意味着您可以创建嵌套的导航组。页面名称中不需要包含 `.mdx`。

<CodeGroup>

```json 常规导航
"navigation": {
  "tabs": [  // 导航标签页
    {
      "tab": "Docs",  // 标签页名称
      "groups": [  // 页面分组
        {
          "group": "Getting Started",  // 分组名称
          "pages": ["quickstart"]  // 页面列表
        }
      ]
    }
  ]
}
```

```json 嵌套导航
"navigation": {
  "tabs": [  // 导航标签页
    {
      "tab": "Docs",  // 标签页名称
      "groups": [  // 页面分组
        {
          "group": "Getting Started",  // 分组名称
          "pages": [  // 页面列表
            "quickstart",  // 普通页面
            {
              "group": "Nested Reference Pages",  // 嵌套分组
              "pages": ["nested-reference-page"]  // 嵌套分组的页面
            }
          ]
        }
      ]
    }
  ]
}
```

</CodeGroup>

## 文件夹

只需将您的 MDX 文件放在文件夹中，然后更新 `docs.json` 中的路径即可。

例如，要在 `https://yoursite.com/your-folder/your-page` 创建页面，您需要创建一个名为 `your-folder` 的文件夹，其中包含一个名为 `your-page.mdx` 的 MDX 文件。

<Warning>

除非将其嵌套在另一个文件夹中，否则您不能使用 `api` 作为文件夹名称。Mintlify 使用 Next.js，它保留顶级 `api` 文件夹用于内部服务器调用。像 `api-reference` 这样的文件夹名称是可以接受的。

</Warning>

```json 带文件夹的导航
"navigation": {
  "tabs": [  // 导航标签页
    {
      "tab": "Docs",  // 标签页名称
      "groups": [  // 页面分组
        {
          "group": "Group Name",  // 分组名称
          "pages": ["your-folder/your-page"]  // 带文件夹路径的页面
        }
      ]
    }
  ]
}
```

## 隐藏页面

未包含在 `docs.json` 中的 MDX 文件不会在侧边栏中显示，但可以通过搜索栏和直接链接访问。
