## 图片

### 使用 Markdown

[Markdown 语法](https://www.markdownguide.org/basic-syntax/#images) 允许您使用以下代码添加图片：

```md
![标题](/path/image.jpg)  // 图片替代文本和路径
```

请注意，图片文件大小必须小于 5MB。否则，我们建议使用 [Cloudinary](https://cloudinary.com/) 或 [S3](https://aws.amazon.com/s3/) 等服务托管图片。然后您可以使用该 URL 进行嵌入。

### 使用嵌入

要获得更多图片自定义选项，您还可以使用 [嵌入](/writing-content/embed) 功能添加图片：

```html
<!-- 设置高度为 200px 的图片 -->
<img height="200" src="/path/image.jpg" />
```

## 嵌入和 HTML 元素

<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/4KzFe50RQkQ"
  title="YouTube 视频播放器"
  frameBorder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
  style={{ width: "100%", borderRadius: "0.5rem" }}
></iframe>

<br />

<Tip>

Mintlify 支持 [Markdown 中的 HTML 标签](https://www.markdownguide.org/basic-syntax/#html)。如果您更喜欢使用 HTML 标签而不是 Markdown 语法，这会很有帮助，并且可以让您创建具有无限灵活性的文档。

</Tip>

### iFrames

在文档中加载另一个 HTML 页面。最常用于嵌入视频。

```html
<!-- 嵌入 YouTube 视频的 iframe -->
<iframe src="https://www.youtube.com/embed/4KzFe50RQkQ"> </iframe>
```
