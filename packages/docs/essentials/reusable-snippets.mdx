## 创建自定义片段

**前提条件**：您必须在 `snippets` 目录中创建片段文件。

<Note>
  `snippets` 目录中的任何页面都将被视为片段，不会被渲染为独立页面。如果您想从片段创建独立页面，请将片段导入到另一个文件中并将其作为组件调用。
</Note>

### 默认导出

1. 在片段文件中添加您想要在多个位置重用的内容。您还可以选择添加变量，这些变量可以在导入片段时通过 props 填充。

```mdx snippets/my-snippet.mdx
Hello world! This is my content I want to reuse across pages. My keyword of the
day is {word}.  // {word} 是可通过 props 填充的变量
```

<Warning>
  您想要重用的内容必须位于 `snippets` 目录中，导入才能正常工作。
</Warning>

2. 将片段导入到目标文件中。

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import MySnippet from "/snippets/path/to/my-snippet.mdx"  // 导入片段

## Header

Lorem impsum dolor sit amet.

<MySnippet word="bananas" />  // 使用片段并传递 word 属性
```

### 可重用变量

1. 从片段文件中导出变量：

```mdx snippets/path/to/custom-variables.mdx
export const myName = "my name"  // 导出字符串变量

export const myObject = { fruit: "strawberries" }  // 导出对象变量

;
```

2. 从目标文件中导入片段并使用变量：

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import { myName, myObject } from "/snippets/path/to/custom-variables.mdx"  // 导入变量

Hello, my name is {myName} and I like {myObject.fruit}.  // 使用导入的变量
```

### 可重用组件

1. 在片段文件中，通过以箭头函数形式导出组件来创建一个接受 props 的组件：

```mdx snippets/custom-component.mdx
export const MyComponent = ({ title }) => (  // 导出接受 title prop 的组件
  <div>
    <h1>{title}</h1>  // 使用 title prop
    <p>... snippet content ...</p>  // 组件内容
  </div>
)

;
```

<Warning>
  MDX 不会在箭头函数体中编译。尽可能使用 HTML 语法，或者如果需要使用 MDX，请使用默认导出。
</Warning>

2. 将片段导入到目标文件中并传递 props：

```mdx destination-file.mdx
---
title: My title
description: My Description
---

import { MyComponent } from "/snippets/custom-component.mdx"  // 导入组件

Lorem ipsum dolor sit amet.

<MyComponent title={"Custom title"} />  // 使用组件并传递 title prop
```
