---
title: "全局设置"
description: "Mintlify 通过 docs.json 文件为您提供对文档外观和风格的完全控制"
icon: "gear"
---

每个 Mintlify 站点都需要一个包含核心配置设置的 `docs.json` 文件。了解下面的 [属性](#properties) 详情。

## 属性

<ResponseField name="name" type="string" required>
项目名称。用于全局标题。

示例：`mintlify`

</ResponseField>

<ResponseField name="navigation" type="Navigation[]" required>
  包含该组内所有页面的组数组
  <Expandable title="Navigation">
    <ResponseField name="group" type="string">
    组的名称。

    示例：`Settings`

    </ResponseField>
    <ResponseField name="pages" type="string[]">
    将用作页面的 Markdown 文件的相对路径。

    示例：`["customization", "page"]`

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="logo" type="string or object">
  Logo 图像的路径或包含 "light" 和 "dark" 模式 Logo 图像路径的对象
  <Expandable title="Logo">
    <ResponseField name="light" type="string">
      浅色模式下的 Logo 路径
    </ResponseField>
    <ResponseField name="dark" type="string">
      深色模式下的 Logo 路径
    </ResponseField>
    <ResponseField name="href" type="string" default="/">
      点击 Logo 时链接到的位置
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="favicon" type="string">
  网站图标（favicon）图像的路径
</ResponseField>

<ResponseField name="colors" type="Colors">
  全局主题的十六进制颜色代码
  <Expandable title="Colors">
    <ResponseField name="primary" type="string" required>
      主颜色。最常用于浅色模式下的高亮内容、章节标题和强调元素
    </ResponseField>
    <ResponseField name="light" type="string">
      深色模式的主颜色。最常用于深色模式下的高亮内容、章节标题和强调元素
    </ResponseField>
    <ResponseField name="dark" type="string">
      重要按钮的主颜色
    </ResponseField>
    <ResponseField name="background" type="object">
      浅色和深色模式下的背景颜色
      <Expandable title="Object">
        <ResponseField name="light" type="string" required>
          浅色模式下背景的十六进制颜色代码
        </ResponseField>
        <ResponseField name="dark" type="string" required>
          深色模式下背景的十六进制颜色代码
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="topbarLinks" type="TopbarLink[]">
  要包含在顶部栏中的链接的 `name` 和 `url` 数组
  <Expandable title="TopbarLink">
    <ResponseField name="name" type="string">
    按钮的名称。

    示例：`Contact us`
    </ResponseField>
    <ResponseField name="url" type="string">
    点击按钮后的 URL。示例：`https://mintlify.com/docs`
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topbarCtaButton" type="Call to Action">
  <Expandable title="顶部栏号召性按钮">
    <ResponseField name="type" type={'"link" or "github"'} default="link">
    Link 显示一个按钮。GitHub 显示提供的 URL 处的仓库信息，包括 GitHub 星标数量。
    </ResponseField>
    <ResponseField name="url" type="string">
    如果是 `link`：按钮链接到的位置。
    
    如果是 `github`：加载 GitHub 信息的仓库链接。
    </ResponseField>
    <ResponseField name="name" type="string">
    按钮内的文本。仅当 `type` 是 `link` 时才需要。
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="versions" type="string[]">
  版本名称数组。仅当您希望在导航栏中使用下拉菜单显示不同版本的文档时使用。
</ResponseField>

<ResponseField name="anchors" type="Anchor[]">
  锚点数组，包含 `icon`、`color` 和 `url`。
  <Expandable title="Anchor">
    <ResponseField name="icon" type="string">
    用于展示锚点的 [Font Awesome](https://fontawesome.com/search?q=heart) 图标。

    示例：`comments`
    </ResponseField>
    <ResponseField name="name" type="string">
    锚点标签的名称。

    示例：`Community`
    </ResponseField>
    <ResponseField name="url" type="string">
      标记哪些页面属于该锚点的 URL 开头部分。通常，这是您放置页面的文件夹名称。
    </ResponseField>
    <ResponseField name="color" type="string">
      锚点图标背景的十六进制颜色。如果您传递一个包含 `from` 和 `to` 属性的对象（每个属性都是一个十六进制颜色），也可以使用渐变。
    </ResponseField>
    <ResponseField name="version" type="string">
      如果您希望在选择正确的文档版本之前隐藏锚点，则使用此属性。
    </ResponseField>
    <ResponseField name="isDefaultHidden" type="boolean" default="false">
      如果您希望隐藏锚点，直到直接将某人链接到其中的文档，则传递 `true`。
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      可选值："brands"、"duotone"、"light"、"sharp-solid"、"solid" 或 "thin"
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="topAnchor" type="Object">
  覆盖最顶部锚点的默认配置。
  <Expandable title="Object">
    <ResponseField name="name" default="Documentation" type="string">
      最顶部锚点的名称
    </ResponseField>
    <ResponseField name="icon" default="book-open" type="string">
      Font Awesome 图标。
    </ResponseField>
    <ResponseField name="iconType" default="duotone" type="string">
      可选值："brands"、"duotone"、"light"、"sharp-solid"、"solid" 或 "thin"
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tabs" type="Tabs[]">
  导航标签页数组。
  <Expandable title="Tabs">
    <ResponseField name="name" type="string">
      标签页标签的名称。
    </ResponseField>
    <ResponseField name="url" type="string">
      标记哪些页面属于该标签页的 URL 开头部分。通常，这是您放置页面的文件夹名称。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api" type="API">
  API 设置的配置。在 [API 组件](/api-playground/demo) 了解更多关于 API 页面的信息。
  <Expandable title="API">
    <ResponseField name="baseUrl" type="string">
      所有 API 端点的基础 URL。如果 `baseUrl` 是一个数组，它将启用用户可以切换的多个基础 URL 选项。
    </ResponseField>

    <ResponseField name="auth" type="Auth">
      <Expandable title="Auth">
        <ResponseField name="method" type='"bearer" | "basic" | "key"'>
          用于所有 API 端点的认证策略。
        </ResponseField>
        <ResponseField name="name" type="string">
        API  playground 中使用的认证参数的名称。

        如果方法是 `basic`，格式应为 `[usernameName]:[passwordName]`
        </ResponseField>
        <ResponseField name="inputPrefix" type="string">
        设计为认证输入字段前缀的默认值。

        例如：如果 `inputPrefix` 为 `AuthKey`，则认证字段的默认输入结果将继承为 `AuthKey`。
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="playground" type="Playground">
      API playground 的配置

      <Expandable title="Playground">
        <ResponseField name="mode" default="show" type='"show" | "simple" | "hide"'>
          playground 是显示、隐藏还是仅显示端点而不添加用户交互性（`simple`）

          在 [playground 指南](/api-playground/demo) 了解更多信息
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="maintainOrder" type="boolean">
      启用此标志可确保 OpenAPI 页面中的键顺序与 OpenAPI 文件中定义的键顺序匹配。

      <Warning>此行为很快将默认启用，届时此字段将被弃用。</Warning>
    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="openapi" type="string | string[]">
  指向您的 OpenAPI 文件的 URL 或相对路径的字符串或字符串数组。
  
  示例：
  <CodeGroup>
    ```json 绝对路径
    "openapi": "https://example.com/openapi.json"  // 外部 OpenAPI 文件 URL
    ```
    ```json 相对路径
    "openapi": "/openapi.json"  // 相对路径的 OpenAPI 文件
    ```
    ```json 多个文件
    "openapi": ["https://example.com/openapi1.json", "/openapi2.json", "/openapi3.json"]  // 多个 OpenAPI 文件
    ```
  </CodeGroup>

</ResponseField>

<ResponseField name="footerSocials" type="FooterSocials">
  社交媒体账户的对象，其中键值对表示社交媒体平台和账户 URL。
  
  示例：
  ```json
  {
    "x": "https://x.com/mintlify",  // X 平台链接
    "website": "https://mintlify.com"  // 网站链接
  }
  ```
  <Expandable title="FooterSocials">
    <ResponseField name="[key]" type="string">
    以下值之一：`website`、`facebook`、`x`、`discord`、`slack`、`github`、`linkedin`、`instagram`、`hacker-news`
    
    示例：`x`
    </ResponseField>
    <ResponseField name="property" type="string">
    社交媒体平台的 URL。
    
    示例：`https://x.com/mintlify`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="feedback" type="Feedback">
  启用反馈按钮的配置

  <Expandable title="Feedback">
    <ResponseField name="suggestEdit" type="boolean" default="false">
    启用允许用户通过拉取请求建议编辑的按钮
    </ResponseField>
    <ResponseField name="raiseIssue" type="boolean" default="false">
    启用允许用户提出关于文档问题的按钮
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="modeToggle" type="ModeToggle">
  自定义深色模式切换。
  <Expandable title="ModeToggle">
    <ResponseField name="default" type={'"light" or "dark"'}>
      如果您希望始终为新用户显示浅色或深色模式，则设置此选项。未设置时，我们默认为用户操作系统的相同模式。
    </ResponseField>
    <ResponseField name="isHidden" type="boolean" default="false">
      设置为 true 以隐藏深色/浅色模式切换。您可以将 `isHidden` 与 `default` 结合使用，强制您的文档仅使用浅色或深色模式。例如：
      
      <CodeGroup>
      ```json 仅深色模式
      "modeToggle": {
        "default": "dark",  // 默认使用深色模式
        "isHidden": true  // 隐藏模式切换按钮
      }
      ```

      ```json 仅浅色模式
      "modeToggle": {
        "default": "light",  // 默认使用浅色模式
        "isHidden": true  // 隐藏模式切换按钮
      }
      ```
      </CodeGroup>

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="backgroundImage" type="string">
  要显示在每个页面背后的背景图像。查看 [Infisical](https://infisical.com/docs) 和 [FRPC](https://frpc.io) 的示例。
</ResponseField>
