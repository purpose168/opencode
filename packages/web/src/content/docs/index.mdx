[**OpenCode**](/) 是一个开源的 AI 编码代理。它可以作为基于终端的界面、桌面应用程序或 IDE 扩展使用。

![使用 opencode 主题的 OpenCode TUI](../../assets/lander/screenshot.png)

让我们开始吧。

---

#### 先决条件

要在终端中使用 OpenCode，您需要：

1. 现代终端模拟器，如：
   - [WezTerm](https://wezterm.org)，跨平台
   - [Alacritty](https://alacritty.org)，跨平台
   - [Ghostty](https://ghostty.org)，Linux 和 macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/)，Linux 和 macOS

2. 您要使用的 LLM 提供商的 API 密钥。

## 安装

安装 OpenCode 最简单的方法是通过安装脚本。

```bash
curl -fsSL https://opencode.ai/install | bash
```

您也可以使用以下命令安装它：

- **使用 Node.js**

      <TabItem label="npm">


          </TabItem>

          </TabItem>

        <TabItem label="pnpm">

          </TabItem>



#### Windows

## 配置

使用 OpenCode，您可以通过配置 API 密钥来使用任何 LLM 提供商。

如果您是第一次使用 LLM 提供商，我们建议使用 [OpenCode Zen](/docs/zen)。它是由 OpenCode 团队测试和验证的精选模型列表。

1. 在 TUI 中运行 `/connect` 命令，选择 opencode，然后前往 [opencode.ai/auth](https://opencode.ai/auth)。

   ```txt
   /connect
   ```

2. 登录，添加您的账单详细信息，然后复制您的 API 密钥。

3. 粘贴您的 API 密钥。

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

或者，您可以选择其他提供商之一。[了解更多](/docs/providers#directory)。

## 初始化

现在您已经配置了提供商，您可以导航到要处理的项目。

```bash
cd /path/to/project
```

然后运行 OpenCode。

```bash
opencode
```

接下来，通过运行以下命令为项目初始化 OpenCode。

```bash frame="none"
/init
```

这将让 OpenCode 分析您的项目并在项目根目录中创建一个 `AGENTS.md` 文件。

:::tip
您应该将项目的 `AGENTS.md` 文件提交到 Git。
:::

这有助于 OpenCode 了解项目结构和使用的编码模式。

## 使用

现在您已经准备好使用 OpenCode 处理您的项目了。随时问它任何问题！

如果您是第一次使用 AI 编码代理，以下是一些可能有帮助的示例。

---

### 提问

您可以要求 OpenCode 向您解释代码库。

:::tip
使用 `@` 键模糊搜索项目中的文件。
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
How is authentication handled in @packages/functions/src/api/index.ts
```

如果代码库中有您没有参与的部分，这会很有帮助。

---

### 添加功能

您可以要求 OpenCode 向您的项目添加新功能。不过，我们首先建议您要求它创建一个计划。

1. **创建计划**

   OpenCode 有一个 _计划模式_，它会禁用其进行更改的能力，而是建议它将如何实现该功能。

   使用 **Tab** 键切换到它。您会在右下角看到一个指示器。

   ```bash frame="none" title="Switch to Plan mode"
   <TAB>
   ```

   现在让我们描述我们希望它做什么。

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   您需要给 OpenCode 足够的细节，以便它理解您想要什么。最好像与团队中的初级开发人员交谈一样与它交谈。

   :::tip
   给 OpenCode 足够的上下文和示例，以帮助它理解您想要什么。
   :::

2. **迭代计划**

   一旦它给您一个计划，您可以给它反馈或添加更多细节。

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   将图像拖放到终端中，将它们添加到提示中。
   :::

   OpenCode 可以扫描您给它的任何图像并将它们添加到提示中。您可以通过将图像拖放到终端中来完成此操作。

3. **构建功能**

   一旦您对计划感到满意，再次按 **Tab** 键切换回 _构建模式_。

   ```bash frame="none"
   <TAB>
   ```

   然后要求它进行更改。

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### 进行更改

对于更直接的更改，您可以要求 OpenCode 直接构建它，而无需先查看计划。

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @packages/functions/src/notes.ts and implement
the same logic in @packages/functions/src/settings.ts
```

您需要确保提供足够的细节，以便 OpenCode 做出正确的更改。

---

### 撤销更改

假设您要求 OpenCode 进行一些更改。

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

但您意识到这不是您想要的。您 **可以使用** `/undo` 命令 **撤销** 更改。

```bash frame="none"
/undo
```

OpenCode 现在将恢复您所做的更改，并再次显示您的原始消息。

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

从这里，您可以调整提示并要求 OpenCode 再次尝试。

:::tip
您可以多次运行 `/undo` 来撤销多个更改。
:::

或者，您 **可以使用** `/redo` 命令 **重做** 更改。

```bash frame="none"
/redo
```

## 分享

您与 OpenCode 的对话可以 [与您的团队分享](/docs/share)。

```bash frame="none"
/share
```

这将创建一个指向当前对话的链接并将其复制到您的剪贴板。

:::note
默认情况下，对话不会被共享。
:::
