OpenCode 1.0 是 TUI 的完全重写。

我们从基于 go+bubbletea 的 TUI（存在性能和功能问题）迁移到了使用 zig+solidjs 编写的内部框架（OpenTUI）。

新的 TUI 与旧版本的工作方式相同，因为它连接到同一个 opencode 服务器。

---

## 升级

如果您当前使用的是以前的版本，您不应该被自动升级到 1.0。但是，某些旧版本的 OpenCode 总是会获取最新版本。

要手动升级，请运行

```bash
$ opencode upgrade 1.0.0
```

要降级回 0.x，请运行

```bash
$ opencode upgrade 0.15.31
```

---

## 用户体验变更

会话历史更加紧凑，仅显示编辑和 bash 工具的完整详细信息。

我们添加了一个命令栏，几乎所有操作都通过它进行。在任何上下文中按 ctrl+p 即可调出它，并查看您可以执行的所有操作。

添加了包含有用信息的会话侧边栏（可以切换）。

我们移除了一些不确定是否有人实际使用的功能。如果缺少重要功能，请提交 issue，我们会快速添加回来。
